投稿の末尾に定型文を挿入するプラグインです。

== Description ==

管理画面「設定 > マイフッターノート」で登録した文章を、
投稿の本文末尾に表示します。
書籍『WordPressプラグイン開発の教科書 1』の題材プラグインです。

== Installation ==

1. zipを「プラグイン > 新規プラグインを追加 > プラグインのアップロード」から追加
2. 有効化
3. 「設定 > マイフッターノート」で文章を登録
